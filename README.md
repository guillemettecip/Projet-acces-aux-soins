# Projet universitaire (M1 IREF) réalisé par Andréa SAINT PAUL et Guillemette CIPRIANO.   

Ce projet analyse les inégalités d'accès aux soins dans les communes françaises. Pour cela, nous avons rassemblé et nettoyé 5 bases de données publiques (hôpitaux, médecins généralistes, urgences et couverture SAS).

Préparation des données : Regroupement et nettoyage de plusieurs fichiers de sources différentes.   
Création d'un score : Calcul d'une note sur 100 (Index Global) pour évaluer l'offre de soins de chaque commune.   
Analyse : Classement des départements et des régions pour repérer facilement les zones les mieux équipées et les déserts médicaux.   

Outils : Python (Pandas), Jupyter Notebook
